# Журнал изменений

## 0.1.0-alpha.1 (не опубликовано)

Первая альфа.

**Продукт**
- Демон фермы `pcdockd`: обнаружение телефонов (USB, ADB, serial; hotplug), состояния с подсказками (`needs_app`, `needs_access`, `needs_auth`,
  `needs_permission`), склейка пути по серийнику, запасной переход на другой путь, закрепление и исключения, видео по спросу, подписки с условиями
  (`fps`, `on_change`), снимок кадра, оригинальное разрешение, звук, ввод (касание с площадью и силой, мышь, клавиатура), передача файлов по ADB.
- Демон автоматизации `pcdock-autod`: сценарии на Lua как автотесты (`assert`, `expect`, шаги, логи), прямой эфир событий с повтором истории, отчёт JSON,
  вложения (кадры при провале), хранение сценариев `<id>.lua` + `index.json`.
- ADB-режим без приложения и без диалога записи экрана (серверный процесс с правами shell); AOA-режим с приложением.
- `pcdock-check`: самопроверка для Linux, macOS, Windows.
- Протокол демонов версии 1: приветствие и версия, номера запросов, пароль, WebSocket с типизированными бинарными фреймами.
- Демо-клиенты: веб (одним файлом) и GUI (pygame).

**Известные ограничения**
- Проверено на Linux (WSL2) и Android 15; Windows, macOS, старые версии Android не проверялись.
- Передача файлов и сценарии на настоящем телефоне не прогонялись.
- Без анализа изображений (CV) в автоматизации. Файлы только по ADB.
- Шифрования и ролей нет (общий токен).

**Изменения относительно прежних версий**: удалены `pcdock-daemon` (в ферму), `pcdock-ffi` и C ABI, старый Python-viewer, модуль `app-adb`.
См. `sdk/docs/migration.md`.
