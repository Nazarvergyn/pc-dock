Телефоны Android под управлением компьютера

Экран, звук, касания, клавиатура и файлы нескольких телефонов через USB. Два небольших демона и один открытый протокол: интерфейс, автотесты и скрипты пишите на чём угодно.

УстановитьБыстрый старт

Альфа-версия 0.1.0-alpha.3. Linux, macOS, Windows. Лицензия MIT или Apache-2.0.

Ферма телефонов

pcdockd держит подключения, находит телефоны сам (hotplug) и выбирает путь: USB-аксессуар, ADB или serial. Подключил кабель и работает.

Автотесты на Lua

pcdock-autod запускает сценарии с проверками, логами и отчётом в JSON. Ход прогона виден в прямом эфире.

Один протокол

JSON и бинарные кадры по TCP, WebSocket и локальной трубе. Пример клиента для браузера и для Python в репозитории.

Оригинальное разрешение

Кадры без уменьшения, видео по спросу: подписчик сам выбирает частоту. Передача файлов в разрешённые папки.

Установка

Linux и macOS

curl -fsSL https://pc-dock.prozorov.me/install.sh | sh

Windows (PowerShell)

irm https://pc-dock.prozorov.me/install.ps1 | iex

Через Rust (cargo)

cargo install --locked --git https://github.com/toxic-sunflower/pc-dock \
    pcdockd pcdock-autod pcdock-check pcdock-usb

Скрипт скачивает последний релиз, проверяет контрольную сумму и кладёт pcdockd, pcdock-autod, pcdock-check и pcdock-probe в ~/.pcdock/bin. Все способы, обновление и удаление: подробная инструкция.

Первые шаги

# 1. Включите на телефоне «Отладку по USB», подключите кабель, проверьте машину
pcdock-check

# 2. Запустите ферму
pcdockd --auto --server-apk pcdock-server.apk

# 3. Запустите автоматизацию (по желанию)
pcdock-autod --farm 127.0.0.1:9001 --data ./autod-data

Подробно, с телефоном, браузерным демо и первым автотестом: быстрый старт.
