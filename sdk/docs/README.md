# PC Dock SDK: документация

Документация по Rust-части продукта: ядро протокола, транспорты, ферма телефонов, C ABI и демон `pcdockd`.
Демо-приложения в состав продукта не входят и здесь не описаны.

## Что это

Библиотека, которая подключается к Android-телефонам, показывает их экран (картинка и звук) и отправляет на них ввод
(касания с площадью и силой, мышь, клавиатура). Телефонов может быть много, подключаются они разными путями
(USB-аксессуар AOA, ADB, последовательная труба), подключение и отключение обрабатываются автоматически.

Пользоваться можно тремя способами:

| Способ | Для кого | Документ |
|---|---|---|
| Rust-крейт `pcdock-farm` | приложения на Rust | [farm.md](farm.md) |
| C ABI (`libpcdock_ffi`, `pcdock.h`) | C, C++, Python, C#, Go и всё, что умеет вызывать C | [c-abi.md](c-abi.md) |
| Демон `pcdockd` + сокеты (TCP, WebSocket, локальная труба) | любой язык, браузер, отдельный процесс | [daemon.md](daemon.md) |

## Что проверено, а что нет

Проверено на реальных телефонах (Redmi A5 и Oppo CPH2505, Android 15, Linux в WSL2): ADB-режим (запуск сервера, видео, касания,
клавиша, поворот, звук как канал), AOA-режим на Redmi (рукопожатие, видео, ввод), потеря и возврат телефона, состояния
`needs_app` и `needs_access`, обнаружение двух телефонов, события hotplug. Остальное перечислено в разделе
«Известные ограничения» в [operations.md](operations.md).
