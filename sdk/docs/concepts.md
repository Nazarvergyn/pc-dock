# Понятия

## Телефон и номер

**Телефон** это физическое устройство. Ферма даёт ему **номер** (`PhoneId`, целое от 1). Номер используется во всех командах
и событиях. Пока ферма работает, телефон с тем же серийником получает тот же номер.

## Пути подключения (транспорты)

| Путь | `transport` | Что нужно на телефоне | Что даёт |
|---|---|---|---|
| USB-аксессуар (AOA) | `usb` | установленное приложение PC Dock; подтверждение запуска; разрешение записи экрана | ввод как от настоящих HID-устройств, режим работы без отладки |
| ADB | `adb` | включённая отладка по USB, подтверждённый компьютер | ничего не устанавливается, диалога записи экрана нет |
| Serial | `serial` | микроконтроллер, гоняющий байты | для железных док-станций |

Подробно: [transports.md](transports.md).

## Факт обнаружения (`Sighting`)

Источники обнаружения (USB, ADB, serial) выдают **факты**: «виден телефон: путь, адрес, серийник (если известен)». Факт может
нести **помеху** (`Issue`): `NoAccess` (нет прав на USB-устройство) или `Unauthorized` (ADB ждёт подтверждения). Решения
принимает ферма, источник только сообщает.

## Состояния телефона

| Состояние | JSON | Значение | Что делать человеку |
|---|---|---|---|
| `Appeared` | `appeared` | замечен | ничего |
| `Connecting` | `connecting` | идёт подключение или переподключение | подождать |
| `Ready` | `ready` | рукопожатие прошло, видео и ввод работают | ничего |
| `NeedsPermission` | `needs_permission` | приложение запущено, захвата экрана нет | разрешить запись экрана на телефоне |
| `NeedsApp` | `needs_app` | телефон в режиме аксессуара, но приложение молчит | установить приложение, подтвердить запуск для аксессуара, проверить экран телефона |
| `NeedsAccess` | `needs_access` | USB-устройство видно, но открыть его нельзя | Linux: правила udev; Windows: драйвер WinUSB |
| `NeedsAuth` | `needs_auth` | ADB видит телефон, но компьютер не подтверждён | нажать «Разрешить отладку» на телефоне |
| `Lost` | `lost` | телефона нет дольше `lost_after` | подключить |

Событие `State` несёт подсказку `detail` на русском (пустую, если делать ничего не нужно).

Типовые переходы: `appeared → connecting → ready`; при обрыве связи `ready → connecting → ready`; при пропаже
`… → lost` (после `lost_after`, по умолчанию 45 с); при возвращении `appeared → connecting → ready` под прежним номером.

## Обнаружение

Ферма опрашивает источники каждые `every` (2 с) и сразу, когда источник сообщил об изменении (событие hotplug libusb).
Для каждого факта применяются **правила приёма** (`Rules`):

1. Закреплённый телефон (`pinned`) принимается всегда.
2. Телефон, закреплённый за транспортом по серийнику (`adb:СЕРИЙНИК`), по другим путям не принимается.
3. Иначе телефон принимается, если включено `auto` и он не попал под `except`.

`except` принимает: семейство (`usb`), адрес вида `usb:1-2.3` или `adb:СЕРИЙНИК`, либо просто серийник.

Формат закрепления (`PhoneSpec`): `usb` (любой USB-телефон), `usb:1-2.3` (USB-порт), `usb:СЕРИЙНИК`, `adb:СЕРИЙНИК`,
`serial:ПУТЬ`.

## Выбор пути, если телефон виден несколькими

Факты одного телефона (один серийник) объединяются. Для выбора пути факты ранжируются:

1. сначала **здоровые** (без помехи);
2. затем путь, **заданный для этого телефона** (`prefer`), либо путь, **доведший телефон до `ready` раньше** (ферма запоминает
   на время работы);
3. затем общий порядок `order` (по умолчанию USB, ADB, serial).

**Запасной переход (fallback).** Если выбранный путь не становится рабочим (`needs_app` или `needs_access`) дольше
`fallback_after` (по умолчанию 20 с), а у телефона есть другой здоровый путь, ферма переводит телефон на него под тем же
номером. Путь, который уже не сработал, не повторяется, пока телефон не пропадёт. Типичный случай: первое подключение,
приложения на телефоне нет, USB-путь даёт `needs_app`, через 20 с ферма берёт ADB.

Отключить: `fallback_after = None` (ключ JSON `fallback_after_ms: 0`, флаг `--no-fallback`).

## Заглушка вместо канала

Если телефон виден, но подключиться нельзя (нет прав, нет подтверждения), ферма ставит вместо канала заглушку: телефон
остаётся в списке с состоянием и подсказкой. Когда помеха исчезает, ферма ставит настоящий канал под тем же номером, без
участия потребителя.

## События фермы (`FarmEvent`)

| Событие | Поля | Когда |
|---|---|---|
| `Appeared` | телефон, транспорт, адрес, серийник | найден новый телефон или телефон перешёл на другой путь |
| `State` | телефон, состояние, подсказка | состояние изменилось |
| `Lost` | телефон | телефон пропал дольше `lost_after` |
| `Connected` | телефон, версия протокола, возможности, имя | рукопожатие с телефоном |
| `Display` | размер потока и экрана, dpi, поворот | размер или поворот изменились |
| `Video` | кадр: номер, кодек, ключевой, метка времени, данные | пришёл кадр (только от телефонов под наблюдением) |
| `AudioConfig` / `Audio` | кодек, частота, каналы / метка времени, PCM | звук |
| `Status` | код, текст | сообщение телефона (например, проекция остановлена) |
| `PeerSilent` | телефон | телефон не отвечает |
| `Malformed` | текст | телефон прислал плохие данные |
| `Disconnected` | причина | сессия закрыта |
| `LinkDown` | текст | связь потеряна, идёт переподключение |
| `Warning` | текст | предупреждение (ввод отклонён, ошибка фабрики и т. п.) |

## Ввод

Координаты касаний и курсора: доли экрана `0.0..1.0` **от отображаемой картинки** (с учётом поворота). Ферма сама пересчитывает
их под поворот телефона. Размер пятна и сила касания тоже доли; не заданные берутся по умолчанию.

Устройства ввода: касание (тачскрин), мышь, клавиатура. Каждое можно включать и отключать командой `device_enable`;
отключённое отпускает нажатое и снимается с телефона. Клавиши задаются кодами USB HID (страница Keyboard): `0x04` = A,
`0x29` = Esc (в Android действует как «Назад»), `0xE0..0xE7` модификаторы.

Мышь по AOA: относительная, положение курсора оценивается на ПК (прижим к углу, затем смещение); возможны расхождения из-за
ускорения указателя Android (поправка `mouse_gain`). По ADB мышь подаётся событиями мыши напрямую.
