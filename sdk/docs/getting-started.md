# Быстрый старт

От чистой машины до первого автотеста на телефоне. Время: 10–15 минут. Предполагается, что вы уже [установили](install.md) программы.

## 1. Подготовьте телефон

Выберите путь подключения (можно оба, ферма выберет сама):

- **ADB** (проще для старта, приложение на телефоне не нужно): включите «Для разработчиков» → «Отладка по USB». Подключите кабель и на телефоне нажмите
  «Разрешить» (отметьте «Всегда разрешать»).
- **AOA** (USB-аксессуар, приложение): установите приложение из релиза (`adb install -r pcdock-app-<версия>.apk`), при подключении подтвердите запуск для
  аксессуара и разрешите запись экрана.

Подробности для Xiaomi, Oppo и других: [operations.md](operations.md#4-подготовка-телефона).

## 2. Проверьте машину

Подключите телефон кабелем и запустите:

```bash
pcdock-check
```

Команда покажет, видит ли ваш компьютер телефон, есть ли доступ к USB и ADB, готов ли телефон, какой размер экрана и идёт ли поток кадров. По каждому провалу она пишет, что делать.
Типичные первые проблемы: нет прав на USB (Linux: правила udev, [transports.md](transports.md#linux)), не нажато «Разрешить» на телефоне, в WSL2 не проброшен USB ([transports.md](transports.md#wsl2)).

С проверкой ввода (на телефоне выполнятся свайп вниз, вверх и «Назад»): `pcdock-check --input`.

## 3. Запустите ферму

Для ADB-режима нужен APK сервера из релиза (`pcdock-server-<версия>.apk`); ферма сама положит его на телефон:

```bash
pcdockd --auto --server-apk pcdock-server-v0.1.0-alpha.3.apk
```

Должны появиться строки `автообнаружение включено` и при подключении телефона событие `Appeared`, затем состояние `ready`.
Ферма слушает только свой компьютер: TCP `127.0.0.1:9001`, WebSocket `127.0.0.1:9002`, локальную трубу `pcdock`.

Файлы на телефон и обратно включаются флагом `--files`, звук `--audio`. Все параметры: [daemon.md](daemon.md#параметры).

## 4. Посмотрите экран и поуправляйте

Откройте веб-демо из репозитория (`demos/web/index.html`) в браузере, нажмите «Подключить» рядом с адресом фермы (`ws://127.0.0.1:9002`). Телефон появится
плиткой: видно экран, мышь работает как касание, можно переключить путь подключения (USB, ADB, serial) и отправить файл.

Демо это пример клиента в одном HTML-файле: все команды протокола видны в нём как `send(...)`. Клиент можно написать на любом языке:
[protocol.md](protocol.md), пример на Python в [daemon.md](daemon.md#пример-клиента-на-python-tcp).

## 5. Первый автотест

Запустите демон автоматизации рядом с фермой:

```bash
pcdock-autod --farm 127.0.0.1:9001 --data ./autod-data
```

В веб-демо в блоке «Автоматизация» подключитесь к `ws://127.0.0.1:9102`, нажмите «Новый» и вставьте сценарий:

```lua
test("шторка открывается", function()
  local p = phones()[1]
  assert.truthy(p:wait_ready(10), "телефон готов")
  step("свайп вниз")
  p:swipe(0.5, 0.01, 0.5, 0.5, {duration = 0.3})
  expect.truthy(p:wait_change(3), "экран изменился")
  p:key("esc")
end)
```

Нажмите «Сохранить», затем «Запустить». Ход прогона виден в прямом эфире: шаги, логи, провалы, а при провале сохраняется кадр. Итоговый отчёт
в JSON лежит в `./autod-data/runs/<номер>/`. Все функции Lua: [autod.md](autod.md).
