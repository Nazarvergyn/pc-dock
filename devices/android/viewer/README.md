# viewer — ПК-сторона PC Dock (Android)

Демон и окно просмотра: переводит телефон в режим USB-аксессуара, ведёт сессию
протокола v2 через Rust-ядро (`pcdock-ffi`), показывает кадры и отправляет ввод.
Питон здесь делает только транспорт (pyusb), окно (pygame) и звук — весь протокол,
HID-отчёты и согласование живут в ядре. Подробности и общая схема — в
[`../README.md`](../README.md).

## Сборка ядра

```bash
cd ../../sdk && cargo build -p pcdock-ffi
```

Путь к библиотеке: `sdk/target/debug/libpcdock_ffi.so` (находится сам) или через
переменную окружения `PCDOCK_LIB`.

## Запуск

```bash
uv run main.py                 # все устройства ввода включены
uv run main.py --no-mouse      # без мыши (аналогично --no-touch, --no-keyboard)
uv run main.py --no-audio      # без звука телефона
```

Скрипт работает бесконечно: ищет телефон, делает AOA handshake, ведёт сессию SDK,
принимает поток и сам переподключается при отключении кабеля. Закрыть — закрыть окно.

Курсор: в режиме мыши курсор ОС над картинкой скрыт (курсор рисует телефон),
в режиме касания — скрыт тоже, рисуем свой кружок. Тачскрин и мышь — радио:
один всегда включён, переключение `F10`/`F11` (повторное нажатие активного игнорируется).

## Ввод в окне

| Действие | Результат на телефоне |
|---|---|
| Левая кнопка, перетаскивание | тап, свайп (тачскрин) |
| Движение мыши | курсор |
| Правая кнопка | «Назад» |
| Средняя кнопка | средняя кнопка мыши |
| Колесо | прокрутка (дробь копит ядро) |
| Наклон колеса / горизонтальный жест | прокрутка по горизонтали (AC Pan → REL_HWHEEL, проверь на телефоне) |
| Клавиши | клавиатура |
| `F10` / `F11` / `F12` | тачскрин / мышь / клавиатура (на телефон не отправляются) |
| `F9` | звук вкл/выключить; колесо над кнопкой «Звук» — громкость |
| `F8` / кнопка «Будить» | включить экран телефона на минуту (ввести PIN) |

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | поиск устройства, handshake, транспорт bulk, цикл сессии SDK |
| `sdk.py` | ctypes-обвязка над `pcdock-ffi` (без протокола на Питоне) |
| `ui.py` | окно `pygame`, команды ввода в сессию, курсор, панель |
| `audio.py` | воспроизведение PCM через `pygame.mixer` |

## Параметры

В `main.py`: `NO_DATA_RESET_AFTER` (6 с тишины до сброса USB), `RESET_MIN_INTERVAL`,
`RESET_MAX_TRIES`, `FREEZE_AFTER` / `REQUEST_FRAME_EVERY` (детектор зависшего видео).
