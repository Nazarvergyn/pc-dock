# Статус — PC Dock

Обновлено: 2026-11-12, версия 0.1.0-alpha.1. Проверено на: Redmi A5 (`25028RN03A`, HyperOS) и Oppo CPH2505 (ColorOS), оба Android 15; ПК Linux в WSL2 (USB через `usbipd`).

## Работает (проверено на телефонах)

- **ADB-режим** (серверный процесс с правами shell, приложение и диалог записи экрана не нужны): запуск с ПК, `ready`, видео в оригинальном разрешении, касание
  (свайп открыл и закрыл шторку), клавиша Esc, мышь (команды принимаются), поворот экрана, звук (канал работает; громкость не проверялась). Redmi и Oppo.
- **AOA-режим** (USB, приложение): рукопожатие, `ready`, видео, касание, Esc, мышь, автозапуск приложения системой, переживание блокировки экрана, переподключение кабеля без новых диалогов. Redmi.
- **Ферма:** обнаружение двух телефонов, потеря и возврат под прежним номером, состояния с подсказками (`needs_app`, `needs_access`), события hotplug, выбор по серийнику.
- Остальное проверялось только тестами с фейковыми телефонами (около 180): запасной переход на другой путь, предпочтение пути, пароль, подписки с условиями, видео по спросу, медленные клиенты, автоматизация (Lua, прогоны, отчёты, прямой эфир), файлы, самопроверка.

## Не проверено на железе

- Передача файлов по ADB (тесты на фейковом ADB-сервере).
- Сценарии автоматизации на настоящем телефоне; видео по спросу и подписки с условиями на настоящем телефоне после последних изменений протокола.
- Звук с реальным источником (в тесте ничего не играло), выключенный экран и побудка, результат работы мыши, два телефона одновременно с видео и вводом, оба режима на обоих телефонах.
- Windows, macOS, Android ниже 15, сутки работы в фоне (HyperOS), возврат AOA-телефона в обычный режим после остановки демона.
- Serial-транспорт на микроконтроллере.

## Известные проблемы и ограничения

- В WSL2 новый USB-ID телефона (режим аксессуара, смена режима USB у Oppo) надо разрешить в `usbipd` вручную; без этого телефон пропадает из WSL.
- Диалог записи экрана (AOA) нужен заново после перезапуска приложения, перезагрузки телефона или остановки в уведомлении.
- ADB-сервер проверен только на Android 15 (закрытые интерфейсы Android могут отличаться); запасного пути для старых версий нет.
- Нет шифрования в демонах, роли доступа вне продукта. Нет анализа изображений в автоматизации. Файлы только по ADB.

Подробно: `sdk/docs/operations.md` (раздел «Известные ограничения»). Решения: `DECISIONS.md`. Ручная проверка: `TESTING.md`.
